# Dashboard setup guide

This guide has been updated for the already-deployed `monir-website-admin` Worker.

Please follow **[ADMIN-DASHBOARD-UPDATE-GUIDE.md](ADMIN-DASHBOARD-UPDATE-GUIDE.md)**. It explains how to replace the incomplete website JSON data with all legacy entries, update the public pages, redeploy the expanded Worker, and verify the complete dashboard.

Your existing Cloudflare KV namespace, OAuth application, Worker URL, and three secrets should be retained. Do not recreate or delete them.
